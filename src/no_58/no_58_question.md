設問58


モジュールシステムの説明として正しいものを選べ（2つ）



A. メモリの効率を向上させる

B. クラスパスを拡張する

C. アプリケーションの可搬性を向上させる

D. アプリケーションの起動速度を向上させる

E. アプリケーションの依存関係を管理可能にする

F. アクセスコントロールをより強固にする



#ポイント
Java モジュールシステム（JPMS）が提供するメリットを、Java SE 17 の仕様レベルで整理すると E（依存関係管理） と F（アクセスコントロール強化） が正しい選択肢になる。



#E. アプリケーションの依存関係を管理


**・requires により依存モジュールを明示**  

**・exports により公開パッケージを明示**  

**・クラスパスの「依存関係が勝手に混ざる問題」を解消**  


```
依存関係の解決がコンパイル時に行われる（クラスパスは実行時のみ）

→ 依存関係の明確化・管理が可能になる
```


#F. アクセスコントロール管理
JPMS のもう一つの大きな目的  

--------------
**・exports されていないパッケージは外部からアクセス不可**  

**・リフレクションによるアクセスも opens が必要**  

**・クラスレベルではなく「パッケージ単位」でアクセス制御できる**  

--------------

*→ クラスパス時代より強固なアクセス制御が可能*
