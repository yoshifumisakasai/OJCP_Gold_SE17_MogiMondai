設問24

無名モジュールについて正しい説明を選びなさい（２つ選択）



A. 無名モジュールは、クラスパス上に配置する

B. 無名モジュールは、モジュールパス上に配置する

C. 無名モジュールは、無名モジュールのみ参照できる

D. 無名モジュールは、名前付きモジュールを参照できる。また、名前付きモジュールからも無名モジュールを参照できる

E. 無名モジュールは、名前付きモジュールを参照できる。ただし、名前付きモジュールからは無名モジュールは参照できない




#🧭 出題者の意図（試験観点）
この問題は以下を理解しているかを試す：

*無名モジュールは classpath に置かれる*  

*無名モジュールはすべてのモジュールを参照できる（最強）*  
**（しかし名前付きモジュールは無名モジュールを参照できない（片方向）**  


*module-path に置かれた JAR は無名モジュールにならない（自動モジュールになる）*  




#🎁 最短暗記セット
・無名モジュール＝classpath の JAR  

・自動モジュール＝module-path の JAR（module-info なし）  

・無名モジュールは全部参照できる（最強）    

・名前付きモジュールは無名モジュールを参照できない（片方向）  

・exports は無名モジュールには効かない（無視される）  


```
Unnamed Module (classpath)
        ↓ 参照できる
Automatic Module (module-path)
        ↓ 参照できる
Named Module (module-info)
```
※逆方向は 参照できない。
