#選択肢判定


A. == 0 は誤り
**read() が 0 を返すのは 文字コードが 0 のときだけ**    
つまり NULL文字（\u0000） のときだけループすることになる  



B. 正解
!= -1 は EOF 判定として正しい。
**FileReader.read() の戻り値は、読み込んだ 1文字の Unicode コードポイント（0〜65535）で、ファイル終端（EOF）に達したら -1**  

##「コードポイント」  
`“Unicode が各文字に割り当てた固有の番号（整数）” のこと`  
`Java の read() が返すのは、この 文字番号（code point）を int で返す`   



C. == -1 は EOF のときだけループ  
つまり 1回もループしない   
*(char[]) c はキャスト不能 → コンパイルエラー*  


D. != 0 は誤り
0 は NULL文字なので、普通の文字は全部通るが、
*(String)c はキャスト不能 → コンパイルエラー*  

E. 条件は正しいが (String)c が誤り
c は int
*String にキャストできない → コンパイルエラー*
